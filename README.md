# ТАБЛЕТКА

Android-приложение для напоминаний о приёме лекарств.

## Первая версия
- добавление лекарства;
- время приёма;
- курс 7 / 10 / 14 / 30 дней или постоянно;
- количество таблеток;
- экран «Сегодня»;
- действия «Принял», «+10 минут», «Пропустить»;
- локальное хранение данных;
- Android Local Notifications;
- проверка новой версии;
- автоматическая сборка APK через GitHub Actions.

## APK
После каждого изменения в ветке `main` GitHub Actions собирает `app-debug.apk` и публикует его как artifact, а также обновляет тестовый pre-release `test-latest`.

## Важно про обновления Android
Android не разрешает обычному приложению незаметно устанавливать новый APK без участия пользователя. Поэтому приложение проверяет версию и открывает страницу новой версии, а пользователь подтверждает установку. При публикации через Google Play можно включить штатные автоматические обновления магазина.

## Медицинская безопасность
Приложение не назначает лекарства и дозировки. Пользователь переносит в него схему, назначенную врачом.
